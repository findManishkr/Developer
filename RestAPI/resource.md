### api
* API is a structured, secure, and standardized way for software systems to communicate with each other using requests and responses.


- 1️⃣ REST Uses HTTP
Interview Definition (English)

A REST API uses the HTTP protocol for communication between client and server.


- 2️⃣ REST Is Stateless
Interview Definition (English)

REST APIs are stateless, meaning each request from the client contains all the information required for the server to process it.
